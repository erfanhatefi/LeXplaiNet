## Usage Instructions

This repository provides example notebooks for using the `lexplainet` package to generate Layer-wise Relevance Propagation (LRP) explanations for neural networks. The main logic is demonstrated in the following tutorials:

### 1. Explicit LRP for ResNet (see `tutorial_0_explain_resnet_explicit_lrp.ipynb`)

- **Model Preparation:**
  - e.g., Load a pretrained ResNet18 model from torchvision.
  - Canonize and wrap the model using `lexplainet.explicit` functions, e.g. `ResNet18_canonized`, and apply LRP rules (developed explicitely using `torch.autograd.Function`) via a composite dictionary.
- **Explanation:**
  - Use `explain_model_prediction` to compute relevance scores for an input image.
  - Visualize the relevance heatmap with `plot_heatmap` from `lexplainet.heatmap`.

### 2. Implicit LRP for ResNet (see `tutorial_1_explain_resnet_implicit_lrp.ipynb`)

- **Model Preparation:**
  - Load a pretrained ResNet model.
  - Canonize the model with `canonize_resnet` and patch layers with LRP rules using `patch_composite` from `lexplainet.implicit`. Done only via implicit rules in which modify the forward pass merely such that the gradient times input will be equivalent to LRP's explicit formulation.
- **Explanation:**
  - Forward an image through the model, compute gradients, and obtain relevance via muliplication of input with gradients.
  - Normalize and visualize the heatmap with `plot_heatmap`.

### 3. LRP for Language Models (see `test_implicit_rule_llm.ipynb`)

This is the same as implictly computing relevances for the ResNet but only by patching extra functions and modules inside language transformers (i.e., attnetion blocks, gated and non-gated MLP blocks)
- **Model Preparation:**
  - Load a transformer-based language model (e.g., Llama) and tokenizer.
  - Patch model components with LRP rules using `patch_composite` and related functions from `lexplainet.implicit`.
- **Explanation:**
  - Compute input relevance by backpropagating from the output logits.
  - Visualize token-level relevance with `plot_text_heatmap`, `pdf_heatmap`, or `interactive_text_heatmap` from `lexplainet.heatmap`.
